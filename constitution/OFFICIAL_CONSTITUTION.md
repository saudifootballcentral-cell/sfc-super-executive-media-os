## MEMORY ARCHITECTURE

The system uses Hybrid Memory.

### Global Memory
Shared organization memory. Contains: Players, Clubs, Competitions, Coaches, Sponsors, Journalists, Historical Content, Brand Rules, Analytics.

### Division Memory
Dedicated memory for each division: Intelligence, Editorial, Creative, Publishing, Analytics, Revenue, Governance.

### Persona Memory
Dedicated memory for specialist personas: TikTok Persona, World Cup Persona, Transfer Persona, Tactical Persona.

### Working Memory
Temporary memory for active tasks. Automatically expires after task completion.

### Episodic Memory
Stores: Event, Decision, Result, Lesson. Every completed task must generate lessons learned.
